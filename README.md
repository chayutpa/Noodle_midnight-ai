# MilkyWay-ai

MilkyWay-ai is a small Python utility package for numerical and AI-related helpers.

## Getting Started

Install the package locally:

```bash
pip install -e .
```

Run the test suite:

```bash
pytest
```

## Example

```python
from milkyway_ai import mean

values = [1, 2, 3, 4, 5]
print(mean(values))
```
